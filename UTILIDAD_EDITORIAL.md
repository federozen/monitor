# Utilidad editorial

| Módulo | Trabajo manual que reemplaza |
|---|---|
| Resumen 4H | Recorrer portales y reconstruir el corte |
| Qué cambió | Comparar títulos y recordar versiones anteriores |
| Acciones | Decidir qué publicar, actualizar o verificar primero |
| Olé Hoy | Revisar manualmente qué ya fue publicado o actualizado |
| Hallazgos | Buscar rarezas internacionales poco obvias |
| Fuentes | Descubrir silenciosamente qué cobertura se está perdiendo |
| Buzón social | Recordar enlaces recibidos por chats o redes |
| Auditoría | Preguntar por qué apareció o se excluyó un tema |
| Parte ampliado | Redactar un informe narrativo solo cuando vale el costo |

El éxito se mide por acciones útiles y navegación ahorrada, no por volumen de titulares.
